# UI Screenshots & Inspiration Designs Reference

This directory holds visual design assets, mockups, layouts, and screenshots that serve as design targets or inspiration references for the Socials Arc platform.

## How to use:
1. **Drop inspiration designs**: Put any screenshot files (`.png`, `.jpg`, `.webp`) in this folder.
2. **Name them descriptively**:
   * E.g. `kanban-workflow-inspiration.png`
   * E.g. `billing-settings-inspiration.png`
3. **Reference them in prompts**:
   * When asking the agent to modify or build a UI, reference the image path:
     > "Make the layout matching the style in @context/screenshots/kanban-workflow-inspiration.png"
4. **Agent Inspection**: The AI agent will read and inspect the screenshot layout to replicate styling elements, spacing, sizing, colors, and layout structure directly.
